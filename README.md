# Исследование надежности заемщиков

## Описание проекта
Заказчик исследования — кредитный отдел банка. Проект направлен на анализ факторов, влияющих на факт погашения кредита в срок. В основе исследования лежат исторические данные банка со статистикой о платёжеспособности клиентов.

## Цели исследования
Определить наличие и характер зависимости между возвратом кредита в срок и следующими метриками клиента:
1. Количество детей.
2. Семейное положение.
3. Уровень дохода.
4. Заявленная цель получения кредита.

## Ход исследования:
* Обзор исходных данных.
* Предобработка данных (поиск аномалий, обработка пропусков, удаление дубликатов, категоризация данных).
* Проверка гипотез и исследовательский анализ.
* Формирование итогового вывода для корректировки модели кредитного скоринга.

## Стек технологий:
* Python, Pandas
